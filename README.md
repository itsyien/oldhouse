# 旧宅 · Old House

一款第一人称恐怖逃生游戏。你被困在一栋八层老公寓里：搜索房间，找到楼梯门的密码，一层一层逃出去。留意灯光、声音和走廊里的危险；有时躲藏或保持安静比逃跑更重要。

**[开始游戏](https://itsyien.github.io/oldhouse/)** · [旧五层版本](https://itsyien.github.io/dontmove/)

## 操作

- **电脑：** WASD 移动，鼠标观察，Shift 冲刺，E 交互，空格跳跃或翻越，Esc 暂停。Tab 查看密码笔记，H 查看规则，1 / 2 切换道具，鼠标左键使用。
- **手机：** 左侧摇杆移动，向前推可冲刺；拖动右侧观察，使用屏幕按钮交互、使用道具和跳跃。

八楼是安全的教学层。游戏提供中文和英文，可在主菜单或暂停设置中切换。建议佩戴耳机，并根据设备性能调整画质。

## 本地运行

需要 Node.js 24。运行 `npm ci` 安装依赖，`npm run dev` 启动本地开发服务器；`npm test` 运行测试，`npm run build` 构建 GitHub Pages 版本。构建输出使用 `/oldhouse/` 路径。
